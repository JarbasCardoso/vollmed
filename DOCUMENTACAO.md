# PRINCIPAIS  COMANDOS DO EXPO/RN
1. `npx create-expo-app@latest nomedoprojeto --template blank-typescrit` -> `Criação do projeto contendo uma base inicial`
2. `npx expo start` -> Inicia o servidor de desenvolvimento.
3.  `npm run reset-project` -> Limpa dos arquivos de apresentação
4. `npx expo install react-dom react-native-web` simula o app no navegador
5. `npx expo install expo-router` -instala as dependencias do expo para utilização de navgação
